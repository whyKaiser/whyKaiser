## About Me

I'm a fresh Computer Science graduate who skipped the "waiting for an internship" phase and just shipped five production-quality applications instead. I care about **software that solves a real, specific problem** for a real, specific user — not portfolio filler.

My work spans **full-stack product engineering** (Flutter + Firebase, React + TypeScript), **applied AI integration** (LLM-powered assistants using Groq and Gemini in production apps), and **AI-assisted game development** (a 3D action-roguelike built in Godot with a custom in-editor AI agent).

I default to **shipping fast and iterating in public** — most of my projects went from idea to a live, deployed product in a single focused session.

## Featured Projects

<details>
<summary><b>🏠 Rent Freeze Checker (فاحص تثبيت الإيجار)</b></summary>
<br/>

A free, privacy-first Arabic tool that tells Riyadh tenants and landlords whether a rent increase or eviction notice complies with Saudi Arabia's 2025–2030 rent freeze decree. Built and shipped end-to-end in a single day.

| | |
|---|---|
| **Stack** | React · TypeScript · Vite · Tailwind CSS |
| **Scale** | Single-page static app, zero backend |
| **Performance** | ~120KB gzipped bundle, sub-second load |
| **Security** | 100% client-side — no data ever leaves the user's device |
| **Impact** | Guides real legal decisions for Riyadh renters with sourced, cited rules |
| **Repository** | [github.com/whyKaiser/rent-freeze-checker](https://github.com/whyKaiser/rent-freeze-checker) |

Deployed via GitHub Actions to GitHub Pages with a fully automated CI/CD pipeline — every push rebuilds and redeploys with zero manual steps.

</details>

<details>
<summary><b>🕌 Dhakker — Pilgrim Assistant</b></summary>
<br/>

A Flutter + Firebase companion app for Hajj and Umrah pilgrims, using GPS geofencing and sensor fusion to automatically count Tawaf and Sa'i circuits — no manual tracking needed.

| | |
|---|---|
| **Stack** | Flutter · Firebase (Auth, Firestore, Storage) · Cloudflare Workers |
| **Scale** | Multi-zone geofencing across 3+ tracked holy sites |
| **Performance** | Kalman-filtered GPS + compass fusion for Tawaf; GPS + pedometer dead-reckoning for Sa'i |
| **Security** | Firestore security rules deployed; API keys proxied through a Cloudflare Worker, never bundled client-side |
| **Impact** | Live SOS system (WhatsApp + Firestore) and a real-time admin congestion dashboard |
| **Repository** | [github.com/whyKaiser/Dhakker](https://github.com/whyKaiser/Dhakker) |

Includes an AI assistant (Groq `llama-3.3-70b`) with voice input/output for hands-free guidance during rituals.

</details>

| | |
|---|---|
| **Stack** | Flutter · Firebase · Provider (state management) |
| **Scale** | 26+ features, 4 live-switchable themes, bilingual AR/EN |
| **Performance** | 17 automated tests passing, 0 static analysis issues |
| **Security** | Anonymous auth by default — no email or account required |
| **Impact** | Database-first nutrition answers with AI (Groq + Gemini Vision) as a clearly-labeled fallback, not the source of truth |

Real streaks, ranks, and challenges — all computed from actual Firestore activity, not simulated gamification.
