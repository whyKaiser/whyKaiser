## About

Computer Science graduate from **Umm Al-Qura University** (Makkah, 2026), working on applications, structured data and practical AI-enabled workflows.

I build with **Flutter, React, TypeScript, Node.js and SQL** — authenticated applications, relational data models, role-based access and grounded guidance flows. Day to day I also do database-support work: data checks, record updates, access troubleshooting and recurring reports.

Most of what I publish is **Arabic-first software for the Saudi market** — pilgrim guidance, property maintenance, nutrition, personal finance — because that's where the gap between "an app exists" and "an app that actually fits the user" is widest.
